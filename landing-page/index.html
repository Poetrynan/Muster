Questions? Answers.

Is it safe if Windows SmartScreen or macOS Gatekeeper displays a warning?
Completely safe. As an independent student open-source project, Muster does not carry an expensive enterprise code-signing certificate, triggering standard OS warnings. On Windows, click “More info” → “Run anyway”. On macOS, grant permission under System Settings → Privacy & Security. On Linux, simply make the .AppImage executable (chmod +x) or install the .deb package.
Does using Muster comply with university and faculty IT policies?
Muster authenticates via standard browser-level SSO and retrieves only the units and files your account is legitimately authorized to access. It incorporates an internal leaky-bucket rate limiter that restricts request frequency well below manual web browsing, causing zero server strain. Please observe your faculty's IT guidelines and copyright rules.
Are my Monash credentials or passwords intercepted or stored?
Never. Authentication runs entirely inside Monash's official login webview container. Your password and Duo MFA prompts communicate directly with Monash identity servers over encrypted HTTPS. Muster never sees, intercepts, or logs plain-text credentials, storing only secure session cookies locally for persistent login.
Does it support course structures across all faculties?
The vast majority of standard Moodle layouts across all faculties are supported out of the box. If a specific unit uses an unconventional structure and certain files are missed, submit the unit code on GitHub Issues and we will deploy parser updates promptly.
Is Muster completely free? Will it ever become paid?
100% free and open source forever, with zero plans for monetization. Created by Monash IT students to streamline coursework management, it requires no third-party account registration. The AI cockpit operates on a Bring-Your-Own-Key model directly connecting to your chosen API or local Ollama with zero middleware markup.
