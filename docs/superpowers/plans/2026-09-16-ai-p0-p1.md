# Muster AI Enhancement P0+P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Muster's AI from a single course-summary tab to a structured judgment engine across the four main-line surfaces (course summary, cross-course priorities, in-course Q&A, study plan) — P0-A/B/C + P1-D/E/F from `doc/AI功能重点加强报告_20260916.md`.

**Architecture:** One Rust streaming engine (`generate_summary_stream`) gains a `mode` parameter selecting among four system prompts (summary / priorities / plan / qa). Every mode outputs Markdown followed by a machine-readable appendix `<!--MUSTER_JSON {...} -->` that the frontend extracts into action cards (graceful markdown fallback). All context is assembled **frontend-side from the local store cache (zero new Moodle requests)** by pure, tested modules: `aiContext.ts`, `courseSearch.ts`, `aiStructured.ts`, `summaryFreshness.ts`.

**Tech Stack:** React 19 + TS + Zustand (idb persist), Tauri 2 + Rust (reqwest SSE), vitest (new, frontend unit tests), cargo test (existing).

**Spec:** `D:\Muster\doc\AI功能重点加强报告_20260916.md` (P0-A context upgrade, P0-B structured output, P0-C freshness, P1-D priorities, P1-E QA, P1-F plan). Settings-switch cleanup from report §1.2 included.

## Global Constraints

- 零新增 Moodle 抓取请求：AI 上下文只读 store 已缓存数据（例外：生成摘要时可调用一次已有 `fetch_course_gradebook`，失败则省略该段）。
- 无 API Key 时所有 AI 入口**整体隐藏**（不灰置、不占位）。
- 结构化输出契约：正文 Markdown + 最后一行附录 `<!--MUSTER_JSON {…} -->`；解析失败必须降级为纯 Markdown 展示，绝不报错给用户。
- 既有护栏不动：11 条防幻觉规则（仅增补）、12k 截断、60s 超时、reasoning_content 思考链、四语 i18n（en/zh/ja/ko 全部同步新增键）。
- 验证铁三角：`cargo test` 0 fail、`tsc` 0 error、`vite build` 成功；前端新增 vitest（若 npm 离线装不上，记录偏差并以 tsc+cargo+手动冒烟代替——预授权偏差）。
- 纪律：feature 分支 `feature/ai-p0-p1`、每个 Task 单独 commit、失败测试先行（TDD）。
- 调试 API（仅本机测试用）：LongCat `https://api.longcat.chat/openai/v1`，model `LongCat-2.0`，key 已存于用户 Muster 设置；该 key 是 reasoning 模型（content 之外的 reasoning_content 已被现有 SSE 解析支持）。
